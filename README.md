# THEMEDLE 🟩🟨⬛

Un juego de palabras estilo Wordle desarrollado en Unity para móvil, con categorías temáticas en español.

---

## Descripción

THEMEDLE es un clon de Wordle con giro temático: el jugador elige una categoría (Animales, Países o Comidas) y un nivel de dificultad antes de cada partida. La palabra secreta se selecciona al azar de los archivos de palabras correspondientes, y el jugador tiene 6 intentos para adivinarla usando el teclado virtual en pantalla o el teclado físico del dispositivo.

---

## Características

- **3 categorías**: Animales, Países, Comidas
- **3 niveles de dificultad**: Fácil (3-5 letras), Medio (6-8 letras), Difícil (9-10 letras)
- **Feedback visual por colores** en tiles y teclado:
  - 🟩 Verde — letra en la posición correcta
  - 🟨 Amarillo — letra presente pero en otra posición
  - ⬛ Gris — letra no está en la palabra
